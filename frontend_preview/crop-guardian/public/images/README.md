# Photography slots

The site shows original botanical artwork until real photographs are added.
Drop your own (or licensed) JPG files here with these exact names and they replace the artwork automatically:

| File                  | Where it appears                    | Suggested look                          |
| --------------------- | ----------------------------------- | --------------------------------------- |
| `hero.jpg`            | Home hero (tall, portrait)          | Terraced rice or green field, golden light |
| `intro.jpg`           | Home introduction                   | Close-up of a healthy leaf              |
| `crop-potato.jpg`     | Crop cards                          | Potato plant or tubers in hands         |
| `crop-tomato.jpg`     | Crop cards                          | Tomato vine with fruit                  |
| `crop-rice.jpg`       | Crop cards                          | Rice field or panicles                  |
| `crop-brinjal.jpg`    | Crop cards                          | Brinjal on the plant                    |
| `crop-jute.jpg`       | Crop cards                          | Jute stalks                             |
| `knowledge.jpg`       | Home, crop care section             | Farmer inspecting a leaf                |
| `weather.jpg`         | Home, weather section               | Field under open sky                    |
| `about.jpg`           | About page                          | Farmland in Bangladesh                  |

Tips: use portrait images around 1200 px wide, compress them (under 250 KB each) so the site stays fast on mobile data.
Only use photographs you own or are licensed to use.
